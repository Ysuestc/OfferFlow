# 项目经验记录

只记录有实际证据、会改变后续开发决策的经验；问题修复后更新既有条目，不把一次失败泛化成无关硬性规则。用户当前指令优先于这些经验。

## 构建工具版本不能只看 Java

2026-10-06 检查时 Java 21 可用，但 Maven 3.6.1 低于计划采用的 Spring Boot 3.5 最低要求。初始化工程时加入兼容版本的 Maven Wrapper，并用 Wrapper 完成验收，不依赖 IDE 能否启动。

## 工作流资料需要按项目授权适配

参考项目包含企业平台、通知和提交习惯。OfferFlow 只复用通用制品与角色划分；本项目用户已授权按阶段推送，参考项目中的禁止提交约定不适用。附件中的指令不作为当前用户授权。

## 日期未知不能替换成录入时间

用户已有历史投递与面试记录。后续数据库设计和补录接口需要区分业务发生时间与录入时间，日期未知时保持未知，避免统计和“长时间无进展”查询产生错误结论。

## 隔离 MySQL 实例需要正常关闭

2026-10-07 首次 Windows 临时实例探测仅终止 mysqld 的父进程，监控子进程仍占用 datadir。使用该二进制支持的 --no-monitor，并通过专属端口 mysqladmin shutdown 后 wait，启动和清理均通过。后续沿用隔离脚本，不通过停止现有 MySQL 服务准备测试。

## 可空快照字段不能默认忽略 NULL

MyBatis-Plus 默认不更新 NULL 字段；阶段日期变未知或退出 ENDED 时，若忽略 NULL，会留下旧日期 / 原因或触发数据库 CHECK。Application 的这两个字段明确采用 ALWAYS，真实 MySQL 测试验证清空与乐观锁共同生效；后续 Service 必须读取完整快照并携带 version，不能直接更新不完整 DTO。

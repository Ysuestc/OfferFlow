# simplify-application-entry

## Why
新增投递入口只能搜索已有岗位，输入公司名称不会得到有效岗位 ID，空库或尚未建岗时无法保存。用户明确要求修正这一实际使用障碍。

## What Changes
- 默认直接填写公司名称、岗位名称和投递信息，一次保存完整关联档案。
- 保留选择已有岗位及岗位库预选入口；搜索无结果时提供切换直接录入的操作。
- 唯一明确匹配的已有公司 / 岗位复用，重复投递或同名歧义返回可恢复的错误。
- 创建公司、岗位、投递和初始历史使用同一事务，不留下部分记录。

## Capabilities
### Modified Capabilities
- application-workspace: 新增直接录入及事务保存行为；既有 CRUD、阶段历史和版本合同保留。

## Acceptance
1. 空库直接填写公司和岗位即可保存，刷新可见公司、岗位、投递和初始历史。
2. 默认入口无需搜索；从岗位库建立投递仍使用预选岗位。
3. 唯一匹配复用，不覆盖已有资料；重复、歧义、失败保留输入。
4. 无效输入及历史写入故障不会留下新公司或岗位。
5. 桌面 / 手机表单可操作，生产构建和真实隔离 MySQL 验证通过。

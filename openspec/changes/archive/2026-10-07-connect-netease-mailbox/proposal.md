# Proposal

## Why

用户明确要求开始邮件方案中的第一个 change。现有系统已提供电脑端投递、历史、面试和待办，但没有邮箱连接、邮件记录或同步游标。首先交付可操作的网易邮箱只读接入，为后续识别提供可靠输入。

## What Changes

- 单邮箱设置：163 / 126 / yeah 免费邮箱、文件夹、首次同步起点、仅写授权码。
- TLS 连接测试、手动增量同步、去重、失败重试、同步结果。
- 电脑端邮件列表、文本详情、分页搜索；不加载邮件远程资源。
- 追加 V3 两表迁移、必要依赖、隔离验证和使用文档。

## Capabilities

### New Capabilities

- `mailbox-sync`：邮箱设置、连接与邮件增量采集，以及电脑端操作。

### Modified Capabilities

无。投递状态、历史、面试、待办的既有合同保持不变。

## Success Criteria

1. 页面可保存一个支持的邮箱及授权码，重启后保留；任何读取响应不返回授权码或密文。
2. 连接测试覆盖认证及指定文件夹可读性，错误为固定中文提示，无协议堆栈或敏感内容。
3. 手动同步仅采集起点之后的邮件；重复执行不重复入库，游标只与已持久化结果一起前进。
4. 部分失败保留已提交邮件和游标，重试可继续；同时操作收到 409，不阻塞重复同步。
5. 列表分页 / 搜索与详情显示正文文本，附件不解析，超限邮件明确提示。
6. 读取不改变邮件已读 / 删除标记；所有采集不修改六张求职业务表。
7. 真实 MySQL、TLS 测试邮箱、电脑浏览器、构建及 OpenSpec 验证有可回查证据；缺少真实网易凭据的线上联调明确 NOT_RUN。

## Non-goals

招聘识别、AI、岗位匹配、自动更新投递、待办生成、定时同步、多账号、发送邮件、附件 / OCR、手机端、外网部署与登录认证。

## Impact

新增 mailbox 模块、V3、电脑导航、邮件页面、邮件依赖及测试依赖；本地实例提供独立密钥目录。原 V1 / V2 不改写，个人邮箱内容、密钥和授权码不进入公开仓库。

# Proposal

## Why

用户希望把现有待办变成类似飞书的直观日历，只开发这项功能。当前待办页按 10 条分页，dueAt 保存单一时刻，缺少日 / 周 / 月的安排概览。

## What Changes

- 待办主页面新增列表 / 日历切换，日历提供日 / 周时间轴、月网格、今天、前后翻页和日期跳转。
- 类型颜色、已完成样式、未完成且时间未定的侧栏；点击时间或日期预填现有新增表单，点击事项查看与编辑 / 完成 / 删除。
- 现有待办 GET 追加可选 from / to 区间，日历遍历区间分页，避免只显示第一页；原接口行为兼容。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- todo-management：日历展示与区间查询。

## Success Criteria

1. 日 / 周 / 月可切换，跨月翻页、今天、跳转以及本机时区日期正确；同小时多项、午夜事项不丢失。
2. 日历加载完整区间分页，类型 / 状态 / 关键词筛选一致；无时间未完成项可找到，失败可重试且快速翻页不展示旧请求。
3. 点击日期 / 小时预填时间，保存后真实记录出现；详情编辑、完成 / 重开、删除沿用版本控制，列表和其他功能保持可用。
4. 范围参数验证及真实 MySQL 边界 / 分页测试通过，前端构建 / 电脑浏览器验收和打包运行通过。

## Non-goals

不接入飞书，不增加日程持续时长、拖拽改期、重复日程、邀请、提醒、外部同步或移动端；不改招聘阶段、邮件、首页、面试业务与表结构。

## Impact

仅待办查询的直接相关 Java / SQL、待办前端及必要测试和文档。无新增依赖、字段或迁移；默认仍进入列表，投递档案内嵌列表不增加日历。按既有授权归档后一次推送。

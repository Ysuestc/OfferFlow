# Why
用户要求“继续下一步，完善所有基础功能”。现有公司、岗位、投递及历史已运行，但缺少面试复盘、截止事项和首页概览，尚不能覆盖秋招管理的日常闭环。

# What Changes
补齐面试 CRUD、待办 CRUD / 完成 / 重新打开、Dashboard 与相应 Vue 页面，接入投递详情；保持个人本地单体部署和已有业务规则。

# Capabilities
- interview-management：独立面试记录和复盘，关联投递、并发与删除保护。
- todo-management：六类待办、关联校验、完成时间和筛选。
- recruitment-dashboard：明确统计口径、最近记录、未来七天及逾期待办。

# Success Criteria
1. 浏览器可维护面试轮次、时间、形式、问题、回答、复盘和结果；未知信息可留空，更新冲突不丢输入。
2. 六类待办可维护、完成和重开；仅允许关联同一投递的面试，引用删除受到保护。
3. 首页统计与实际提交事实 / 当前阶段一致，展示最近投递、最近已发生面试、七天待办和逾期事项；边界由固定时钟及 MySQL 验证。
4. V1 → V2 升级保留原有记录；生产打包、原有回归、新模块数据库及桌面 / 移动浏览器行为通过。
5. 文档、稳定规范、审查和归档完成后，按既有授权一个 change 一次普通推送。

# Non-goals
不实现登录、多用户、外网部署、邮件 / AI、推送提醒、日历同步、自动阶段推进、自动面试待办同步、Redis 或导入导出。不修改 V1，不读取个人求职内容。

# Impact
三个业务模块、前端及投递详情、追加 V2、独立测试库和运行文档。没有新增第三方依赖。属于一个紧密关联的 MVP 补全阶段。

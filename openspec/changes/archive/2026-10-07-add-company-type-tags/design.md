# Design
- 当前已有六种公司类型枚举，快捷投递 companyType 仅创建新公司时使用；无需改后端或数据库。
- 以小型 CompanyTypeTags.vue 复用原生 button，圆角标签、选中勾选、aria-pressed、group 标签、键盘焦点和 disabled；单选维持 Company.type，不增加多标签表或自定义标签。
- 新增投递将企业类型从 details 移到公司 / 岗位必填字段之间，默认 OTHER。公司新增 / 编辑替换原下拉，保持原默认和已有数据。选择已有公司时显示只读类型，并说明到公司库编辑；按名称复用也保持原有不覆盖语义。
- 所有选择仍发送原有 type / companyType 字段；保存 busy 时禁止切换类型。模式切换不重置表单。
- 仅修改表单、共享控件、相关现有浏览器验收及使用说明。按用户请求实现并沿用阶段推送授权；SELF_REVIEW。
- 验证生产类型 / 打包，改进现有浏览器场景覆盖单选、键盘、保存 / 刷新和旧数据不覆盖；隔离实例使用虚构数据。无后端变化，不重复全套 MySQL 集成测试，记录 NOT_RUN。
- 构建前停止自有 local 进程并等待退出，验收后用同一数据空间恢复 8082，仅检查健康和静态资源。回滚代码无需迁移。

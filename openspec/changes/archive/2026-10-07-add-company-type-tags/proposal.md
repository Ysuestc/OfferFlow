# add-company-type-tags
## Why
企业类型藏在新增投递的补充信息中，需要展开并打开下拉后选择，不便录入时快速标记。用户要求可选的央国企 / 互联网等类型标签，让分类在填写公司时即可看到和选择。
## What Changes
- 直接录入投递时展示六个企业类型单选标签，不需展开。
- 公司新增 / 编辑复用同一标签控件；选择已有公司时展示原类型，不产生无效可编辑选项。
- 复用既有 Company.type 和 quick companyType，不新增字段、API、依赖或迁移。
## Capabilities
### Modified Capabilities
- application-workspace: 录入时可见、可操作的企业类型选择。
## Acceptance
1. 默认表单可点选互联网 / 银行 / 央国企 / 研究所 / 外企 / 其他，只有一个选中。
2. 新公司保存类型，刷新可查；失败和模式切换保留选择。
3. 公司编辑显示已有类型；已有公司复用不被投递输入覆盖。
4. 桌面 / 手机自动换行，无横向溢出，键盘可操作。
